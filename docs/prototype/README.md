# AI 私厨 · 交互原型

单文件可点击原型，双击 `index.html` 即可在浏览器打开（无需服务器、无需装设计工具）。

## 包含页面（9 屏）

| # | 页面 | 设备 | 说明 |
|---|---|---|---|
| 01 | 落地页 | 桌面 | 免登录可见：大图 Hero + 导航（登录/注册）+ 三个卖点卡片 |
| 02 | 登录 / 注册 | 桌面 | 一个页面 Tab 切换，登录后进入对话 |
| 03 | AI 对话 | 桌面 | SSE 流式、菜谱结构化回答、左侧会话列表 |
| 04 | 我的库存 | 桌面 | 真实食材图、单位按平均重量折算、概览汇总 |
| 05 | 添加食材（弹窗） | 桌面 | 联想下拉（带缩略图）+ 单位白名单 |
| 06 | 发现菜谱 | 桌面 | 瀑布流卡片、搜索、收藏入口 |
| 07-09 | 对话 / 库存 / 发现 | 移动 | 底部 Tab 导航，图片按 390×844 适配 |

## 怎么用

- **点击页面里的虚线区域**跳转（鼠标悬停会显示目标页面名称）
- **← →** 翻页，**H** 常显热区
- 右上角「适应窗口 / 1:1」切换缩放：1:1 时看真实字号与间距
- **▶ 演示模式**（或按 `P`）：隐藏侧栏与说明，全屏逐页播放，底部悬浮翻页条；`Esc` 退出
- 演示模式下页面里的按钮和热区依然可点，适合现场「点着讲」
