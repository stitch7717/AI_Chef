# AI 私厨 · 交互原型（HTML 版）

**所有页面都是真 HTML 绘制的**，不是截图：按钮可点、Tab 可切、可以缩放，双击 `index.html` 即可打开，无需服务器。

## 页面清单（10 屏）

| # | 页面 | 设备 | 关键交互 |
|---|---|---|---|
| 01 | 落地页 | 桌面 | 点「开始做饭 / 登录 / 免费注册」→ 登录页；点「先看看菜谱」→ 发现页 |
| 02 | 登录 / 注册 | 桌面 | 顶部 Tab 可切换两套表单；点「登 录」→ 对话页 |
| 03 | AI 对话 | 桌面 | 左侧菜单可切到库存 / 发现；回答为结构化菜谱 |
| 04 | 我的库存 | 桌面 | 点「＋ 添加食材」→ 弹窗态；侧栏可切页 |
| 05 | 添加食材（弹窗） | 桌面 | 联想下拉（鸡蛋/鸡胸肉/鸡腿）、单位、折算提示 |
| 06 | 发现菜谱 | 桌面 | 点任意卡片 → 回到对话让 AI 讲做法 |
| 07 | 对话（移动） | 手机 | 底部 Tab 切换三页 |
| 08 | 库存（移动） | 手机 | 底部 Tab；添加按钮进入移动弹窗 |
| 09 | 添加食材（移动） | 手机 | 弹窗宽度自适应 390px 屏 |
| 10 | 发现（移动） | 手机 | 两列网格 |

## 操作

| 操作 | 效果 |
|---|---|
| 点页面内任意按钮 | 跳转到对应页面（本原型内闭环） |
| `←` `→` | 上一页 / 下一页 |
| `H` | 高亮所有可点击区域（虚线） |
| `P` | 进入 / 退出演示模式（全屏、隐藏侧栏与说明） |
| `Esc` | 退出演示 |
| 右上角「适应窗口 / 1:1」 | 切换缩放，1:1 可看真实字号 |

## 素材

`assets/` 内是从真实项目里挑的菜品图与食材图（各 40KB 级），所以整个原型目录只有 1.3MB，可离线使用、可直接压缩发给别人。

## 与真实系统的关系

- 视觉参数（色板、圆角、字号）与 `frontend/src` 一致
- 数据是静态示例，不连后端；真实系统在 `http://localhost:8080`
